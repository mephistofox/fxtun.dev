Справочник по командам клиента `fxtunnel`, флагам, которые работают с любой командой, пресетам безопасности и переподключению. Подсказка по любой команде — `fxtunnel <команда> --help`.

## Команды

| Команда | Что делает |
|---|---|
| `fxtunnel http <порт>` | HTTP-туннель — [«HTTP-туннели»](/docs/http) |
| `fxtunnel tcp <порт>` | TCP-туннель — [«TCP-туннели»](/docs/tcp) |
| `fxtunnel udp <порт>` | UDP-туннель — [«UDP-туннели»](/docs/udp) |
| `fxtunnel` | Туннели из конфигурационного файла — [«Конфигурационный файл»](/docs/config) |
| `fxtunnel init` | Создать `fxtunnel.yaml` в текущей папке |
| `fxtunnel up`, `status`, `down` | Туннели в фоне — [«Daemon-режим»](/docs/daemon) |
| `fxtunnel login`, `logout` | Сохранить или удалить токен — [«Аутентификация»](/docs/auth) |
| `fxtunnel domains` | Зарезервированные поддомены — [«Поддомены»](/docs/subdomains) |
| `fxtunnel presets` | Список пресетов безопасности |
| `fxtunnel update` | Обновить клиент — [«Установка»](/docs/install) |
| `fxtunnel version` | Версия клиента |
| `fxtunnel completion <оболочка>` | Автодополнение для `bash`, `zsh`, `fish` или `powershell` |

## Глобальные флаги

| Флаг | Описание | По умолчанию |
|---|---|---|
| `--config`, `-c` | Путь к конфигурационному файлу | автопоиск |
| `--server`, `-s` | Адрес сервера `host` или `host:port`; без порта подставляется `4443` | `tunnel.fxtun.ru:443` |
| `--token`, `-t` | API-токен | сохранённый `fxtunnel login` |
| `--log-level` | Подробность логов: `debug`, `info`, `warn`, `error` | `warn` |
| `--log-format` | Формат логов: `console` или `json` | `console` |
| `--inspect-addr` | Адрес инспектора | `127.0.0.1:4040` |
| `--no-inspect` | Не запускать инспектор | — |
| `--insecure` | Подключаться к серверу без TLS | — |

Токен можно передать и переменной окружения `FXTUNNEL_TOKEN`, адрес сервера — `FXTUNNEL_SERVER_ADDRESS`. Флаги важнее переменных.

## Пресеты безопасности

Пресет — готовый набор флагов для HTTP-туннеля. Список с описанием показывает команда:

```bash
fxtunnel presets
```

Сейчас есть один пресет — `openclaw`. Он включает Basic Auth с логином `admin` и случайным паролем из 16 латинских букв и цифр; пароль новый при каждом запуске:

```bash
fxtunnel http 3000 --preset openclaw
→ Preset 'openclaw' credentials:
→   Username: admin
→   Password: …
```

Флаги, указанные явно, важнее пресета: если вместе с ним указан `--auth`, действуют ваши логин и пароль.

## Переподключение

Если связь с сервером оборвалась, клиент переподключается сам:

1. Первая попытка — сразу после обрыва.
2. После неудачной попытки клиент ждёт `interval` (по умолчанию 5 секунд) и пробует снова.
3. Каждая следующая пауза вдвое длиннее предыдущей, но не больше 2 минут; к ней добавляется случайный разброс ±20%.
4. Всего клиент делает не больше `max_attempts` попыток; по умолчанию ограничения нет.

После переподключения клиент заново открывает свои туннели и просит тот же поддомен и порт, что получил в первый раз. Таймеры `--auto-close` и `--max-lifetime` начинают отсчёт заново.

Параметры задаются в [конфигурационном файле](/docs/config):

```yaml
reconnect:
  enabled: true
  interval: 5s
  max_attempts: 0
```

У команд `fxtunnel http`, `tcp` и `udp` переподключение всегда включено, с паузой 5 секунд и без ограничения попыток.
