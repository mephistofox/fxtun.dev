UDP-туннель пробрасывает UDP-сервис — DNS, игровой сервер, VoIP. Снаружи он доступен по адресу `fxtun.ru:<порт>`.

```bash
fxtunnel udp <порт> [флаги]
```

> [!NOTE]
> UDP-туннели недоступны на бесплатном тарифе — клиент напишет в лог `UDP tunnels are not available on your plan`. Какие тарифы их включают, смотрите на странице [«Тарифы»](/pricing).

## Запуск

```bash
fxtunnel udp 53
→ Tunnel established!
→ UDP: fxtun.ru:21234
→ Forwarding to localhost:53
```

Порт на сервере выбирается автоматически. Задать его можно флагом `--remote-port` (`-r`) — в диапазоне 20001–30000, если порт не занят:

```bash
fxtunnel udp 53 --remote-port 25353
```

## Примеры

### DNS-сервер

Для туннеля из раздела «Запуск» проверка выглядит так:

```bash
dig @fxtun.ru -p 21234 example.com
```

### Игровой сервер

Например, сервер на движке Source слушает порт 27015:

```bash
fxtunnel udp 27015
→ UDP: fxtun.ru:21234
```

Друг подключается к `fxtun.ru:21234`.

## Ограничения

- Каждый внешний собеседник приходит к вашему сервису со своего локального порта, поэтому ответы возвращаются тому, кто прислал запрос. Собеседник забывается, если 60 секунд не было пакетов ни от него, ни к нему (ответы сервиса тоже продлевают срок); одновременно их может быть до 1024; когда лимит достигнут, забывается тот, с кем дольше всех не было обмена пакетами.
- Размер одной датаграммы — до 65 507 байт.
- `--auto-close` закрывает туннель, если через него указанное время не было пакетов ни в одну сторону. Любой пакет сбрасывает таймер.

## Все флаги

| Флаг | Описание | По умолчанию |
|---|---|---|
| `--remote-port`, `-r` | Порт на сервере, 20001–30000; `0` — выбрать автоматически | `0` |
| `--allow-ip` | Разрешённые IP или подсети, можно повторять | все адреса |
| `--auto-close` | Закрытие при простое, от `1m` до `24h` | — |
| `--max-lifetime` | Максимальное время жизни, от `1m` до `7d` | — |
