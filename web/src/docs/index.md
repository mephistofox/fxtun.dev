---

fxTunnel открывает доступ к сервису на вашем компьютере из интернета: веб-приложению, базе данных, игровому серверу. Клиент подключается к серверу fxtun.ru и получает публичный адрес, трафик с которого приходит на локальный порт.

## Три шага до первого туннеля

1. Установите клиент.
2. Войдите по API-токену из личного кабинета.
3. Запустите туннель к нужному порту.

```bash
fxtunnel login -t sk_fxtunnel_ваш_токен
fxtunnel http 3000
→ https://<поддомен>.fxtun.ru
```
