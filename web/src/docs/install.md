Клиент fxTunnel — один исполняемый файл `fxtunnel`. Установщик скачивает сборку под вашу систему и добавляет её в `PATH`.

## Linux и macOS

```bash
curl -fsSL https://fxtun.ru/install.sh | sh
```

Скрипт определяет систему и архитектуру, скачивает клиент в `~/.local/bin/fxtunnel` и создаёт короткий псевдоним `fxtun`. Если в системе есть `openssl`, скрипт проверяет подпись скачанного файла и не ставит сборку с неверной подписью или без неё.

Если `~/.local/bin` нет в `PATH`, скрипт допишет его в те из файлов `~/.bashrc`, `~/.zshrc` и `~/.profile`, что у вас есть. Чтобы команда заработала в текущем окне, перезапустите терминал или выполните:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

Для установки нужен `curl` или `wget`. Поддерживаются Linux и macOS на процессорах amd64 и arm64 (Apple Silicon тоже).

## Windows

Выполните в PowerShell — права администратора не нужны:

```powershell
irm https://fxtun.ru/install.ps1 | iex
```

Клиент встанет в `%LOCALAPPDATA%\fxTunnel`, рядом появится копия `fxtun.exe`, а папка добавится в `PATH` пользователя. После установки откройте новое окно терминала.

Сборка для Windows есть только под amd64. Файл `.exe` можно скачать и вручную на [странице загрузок](/downloads).

## GUI-клиент

Десктопное приложение с графическим интерфейсом для Linux, macOS и Windows лежит на [странице загрузок](/downloads). Оно работает с тем же API-токеном, что и CLI.

## Проверка установки

```bash
fxtunnel version
→ fxTunnel Client v3.12.0 (built …)
```

Первая строка — версия клиента и время сборки. Дальше команда печатает ссылки на репозиторий и сайт.

## Обновление клиента

```bash
fxtunnel update
→ Already up to date.
```

Клиент спрашивает у сервера номер последней версии. Если есть новее — скачивает её, заменяет исполняемый файл и просит перезапустить клиент.

При каждом запуске туннеля клиент тоже проверяет версию в фоне. О новой версии он просто сообщит и предложит выполнить `fxtunnel update`. Если текущая версия ниже минимальной, которую поддерживает сервер, клиент обновится и перезапустится сам.

> [!TIP]
> Повторный запуск установщика тоже обновляет клиент: скрипт скачивает последнюю сборку поверх старой.
