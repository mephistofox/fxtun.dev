Поддомен — первая часть адреса HTTP-туннеля: `myapp` в `https://myapp.fxtun.ru`. Зарезервированный поддомен закреплён за вашим аккаунтом, и другой пользователь не откроет на нём туннель, даже когда ваш выключен.

## Зачем резервировать

Без резервирования поддомен занят, только пока работает туннель. Стоит его закрыть — имя может взять кто угодно. Зарезервированный поддомен остаётся вашим, а чужой туннель на нём сервер отклонит с ошибкой `subdomain is reserved by another user`.

Резерв нужен и для [своих доменов](/docs/custom-domains): свой домен привязывается к зарезервированному поддомену.

Сколько поддоменов можно зарезервировать, зависит от тарифа — смотрите страницу [«Тарифы»](/pricing).

## Резервирование

В личном кабинете откройте раздел [«Домены»](/domains) и нажмите «Зарезервировать». Кнопка «Проверить» в том же окне сразу покажет, свободно ли имя.

Из командной строки:

```bash
fxtunnel domains add myapp
→ Reserved: myapp → https://myapp.fxtun.ru
```

> [!NOTE]
> Команды `fxtunnel domains` работают от имени вашего аккаунта, поэтому сначала войдите: [«Аутентификация»](/docs/auth).

Если лимит тарифа исчерпан, сервер ответит `maximum domains reached`, если имя уже занято — `subdomain is already reserved`.

## Проверка доступности

```bash
fxtunnel domains check myapp
→ myapp — available
```

Если имя недоступно, в скобках указана причина:

| Причина | Что значит |
|---|---|
| `taken` | Поддомен уже зарезервировал другой пользователь |
| `reserved` | Имя системное, его занять нельзя |
| `invalid` | Имя не подходит под правила ниже |

## Список поддоменов

```bash
fxtunnel domains list
→ Reserved domains (2/5):
→   myapp                 https://myapp.fxtun.ru  (created 2026-09-23)
→   shop                  https://shop.fxtun.ru  (created 2026-09-23)
```

В скобках — сколько поддоменов занято и сколько разрешает тариф. `fxtunnel domains` без подкоманды выводит тот же список.

## Туннель на своём поддомене

Укажите зарезервированное имя во флаге `--domain`:

```bash
fxtunnel http 3000 --domain myapp
→ HTTPS: https://myapp.fxtun.ru
```

Подробнее о флагах — в разделе [«HTTP-туннели»](/docs/http).

## Освобождение

В кабинете нажмите значок корзины на карточке поддомена. Из командной строки:

```bash
fxtunnel domains remove myapp
→ Released: myapp
```

> [!WARNING]
> Освобождённое имя сразу становится доступно другим пользователям.

## Правила для имени

- длина — до 32 символов;
- строчные латинские буквы `a-z`, цифры `0-9` и дефис;
- первый и последний символ — буква или цифра.

CLI переводит заглавные буквы в строчные сам. В кабинете вводите имя строчными — иначе сервер его не примет.

## Системные имена

Часть имён закреплена за сервисом, их нельзя ни зарезервировать, ни занять туннелем. Среди них:

- инфраструктура: `www`, `api`, `app`, `admin`, `dashboard`, `console`, `tunnel`, `ns1`, `dns`, `mx`, `mail`, `smtp`, `ftp`;
- вход и оплата: `login`, `auth`, `account`, `billing`, `pay`, `support`, `help`;
- сервисы: `docs`, `blog`, `status`, `cdn`, `static`, `git`, `vpn`, `proxy`;
- окружения: `dev`, `test`, `stage`, `staging`, `prod`, `demo`, `local`, `localhost`;
- `fxtun`, `fxtunnel`.

Имена с номером вроде `ns5`, `mx2` или `www2` тоже закрыты. Полный список не нужен: `fxtunnel domains check` ответит `reserved`, если имя системное.
