Radmin VPN, Hamachi и ZeroTier решают задачу «поиграть с другом по сети» одинаково: собирают из ваших компьютеров виртуальную локальную сеть поверх интернета. Программу для этого ставит каждый игрок. Туннель делает иначе: клиент ставит только тот, кто держит сервер, а друзья получают адрес вида `fxtun.ru:14215` и подключаются к нему прямо из игры. Если друзьям надоело ставить и настраивать Radmin, туннель — рабочий аналог. Если игра умеет искать сервер только в локальной сети, лучше остаться на виртуальной сети. Ниже разберём обе ситуации без рекламы.

## Как работают Radmin VPN, Hamachi и ZeroTier

Все три программы создают на компьютере виртуальный сетевой адаптер. Компьютеры, которые вступили в одну сеть, видят друг друга так, будто стоят в одной комнате на одном роутере. Игра при этом не знает, что между игроками интернет.

**Radmin VPN.** Бесплатная программа для виртуальных локальных сетей, в том числе для игр по сети с друзьями ([radmin-vpn.com](https://www.radmin-vpn.com/)). Один игрок создаёт сеть с именем и паролем, остальные вступают в неё по тем же имени и паролю ([справка Radmin VPN](https://www.radmin-vpn.com/help/)). Работает только на Windows.

**Hamachi.** Сервис LogMeIn, который создаёт сети, похожие на локальные ([vpn.net](https://vpn.net/)). Клиенты есть для Windows, macOS и Linux. Бесплатно — до пяти компьютеров в сети.

**ZeroTier.** Виртуальная сеть, которая «работает как локальная сеть в любой точке мира» ([документация ZeroTier](https://docs.zerotier.com/start)). Сеть создают в веб-панели, клиент ставят на каждое устройство, вступают по идентификатору сети, а владелец сети подтверждает каждого участника в панели. Клиенты есть для Windows, macOS, Linux, iOS и Android ([загрузки](https://www.zerotier.com/download/)). Бесплатный тариф есть, его лимиты — на [странице тарифов](https://www.zerotier.com/pricing/).

Общий знаменатель у всех трёх один: чтобы сыграть, программа нужна у каждого. Новый друг хочет присоединиться — сначала установка, вступление в сеть, иногда подтверждение, и только потом игра. А если у кого-то сеть не поднялась, вечер уходит на выяснение, у кого из пятерых проблема.

## Чем туннель отличается

Туннель открывает к вашему серверу один порт на публичном адресе. Клиент fxtunnel на вашем компьютере сам подключается к серверу fxTunnel, а тот принимает игроков на адресе `fxtun.ru:<порт>` и передаёт их соединения вашей игре.

Что это меняет на практике:

- **Другу ничего не нужно ставить.** Он вводит адрес в игре, как для любого сервера в интернете. С телефона, с Mac, с Linux, с консоли, если игра там умеет подключаться по адресу.
- **Нет общей сети.** Друг получает доступ к одному порту игры, а не ко всему вашему компьютеру по виртуальной сети. Ваш домашний IP он тоже не видит: он подключается к серверу fxTunnel.
- **Вся настройка на вашей стороне.** Одна команда. Не работает — разбираться надо только с вашим компьютером.

Цена за это тоже есть, и о ней ниже.

## Когда Radmin VPN или ZeroTier всё-таки лучше

Честно: есть случаи, когда туннель не заменит виртуальную сеть.

**Игра ищет сервер только в локальной сети.** Многие игры находят «сервер в LAN» по широковещательным или групповым объявлениям. Так делает, например, Minecraft: открытый для сети мир рассылает объявление на групповой адрес `224.0.2.60:4445` каждые полторы секунды ([minecraft.wiki](https://minecraft.wiki/w/Open_to_LAN)). Туннель пропускает подключения к одному порту, а объявления в локальной сети через него не ходят. Minecraft это не мешает: в нём есть прямое подключение по адресу. Но если в игре нет поля для адреса и она видит только то, что нашла в LAN, туннель не поможет. Оставайтесь на Radmin VPN, Hamachi или ZeroTier: они для таких игр и задуманы. Найдёт ли игра сервер в конкретной виртуальной сети, зависит и от игры, и от программы, так что проверьте на своей связке.

**Игре нужно много портов или прямая связь между всеми игроками.** Один туннель — один порт. Игру с двумя-тремя портами туннель потянет на тарифе Base, открыв по туннелю на порт. Но если игроки должны соединяться друг с другом напрямую, а не через хоста, нужна именно общая сеть.

**Вам нужна сеть, а не игра.** Общие папки, доступ к компьютерам друг друга, несколько сервисов сразу. Это задача виртуальной сети, туннель к одному порту её не решает. Сравнение fxTunnel с сетевыми инструментами для таких задач — в статье [«fxTunnel vs Tailscale vs ZeroTier»](/blog/tailscale-vs-fxtunnel-vs-zerotier/).

Если же в игре есть «Подключиться по IP», а друзья устали ставить Radmin ради одного вечера, туннель проще.

## Переезд с Radmin на туннель: пример с Minecraft

Так выглядит типичная игра через Radmin VPN: вы открываете мир Minecraft Java для сети или запускаете сервер, друзья вступают в вашу сеть Radmin и подключаются к вашему адресу в этой сети. Переезд на туннель занимает пять минут, и делаете его только вы.

**1. Поставьте клиент и войдите.** На Windows в PowerShell:

```powershell
irm https://fxtun.ru/install.ps1 | iex
```

На Linux и macOS:

```bash
curl -fsSL https://fxtun.ru/install.sh | sh
```

Затем в новом окне терминала:

```bash
fxtunnel login
```

Клиент откроет страницу входа в браузере. После подтверждения в терминале появится `Authorized!`. Аккаунт заводится на [fxtun.ru](https://fxtun.ru/register).

**2. Запустите мир с известным портом.** Выделенный сервер Minecraft слушает TCP-порт 25565 ([minecraft.wiki](https://minecraft.wiki/w/Server.properties)). Если вы открываете одиночный мир кнопкой «Открыть для сети», задайте порт сами, например `25565`: без этого игра выбирает его случайно ([minecraft.wiki](https://minecraft.wiki/w/Open_to_LAN)).

**3. Откройте туннель:**

```bash
fxtunnel tcp 25565
```

```console
Connecting to fxtunnel server...
Tunnel established!
TCP: fxtun.ru:14215
Forwarding to localhost:25565
Ready to receive connections
```

**4. Отправьте друзьям адрес** из строки `TCP:`. В Minecraft они выбирают «Сетевая игра», затем «Прямое подключение» или «Добавить сервер», и вводят `fxtun.ru:14215` целиком, с портом. Radmin VPN им больше не нужен.

Minecraft Java работает по TCP, поэтому хватает бесплатного тарифа. Все детали, от `online-mode` до белого списка, — в разборе [«Майнкрафт по сети без Хамачи и белого IP»](/blog/minecraft-multiplayer-without-hamachi/).

Одно отличие от Radmin стоит знать заранее: адрес туннеля может измениться после перезапуска `fxtunnel`. Сервер выдаёт первый свободный порт, а прошлый к этому времени может быть занят. Чтобы номер не прыгал, попросите конкретный порт из диапазона 10000–20000: `fxtunnel tcp 25565 --remote-port 15565`. Если его занял кто-то другой, клиент ответит `Failed to connect: server rejected tunnel: port 15565 is already in use` — выберите другой номер.

## А если игра на UDP

Многие игры работают по UDP: Minecraft Bedrock, Factorio, Project Zomboid. Для них команда та же, только `udp`:

```bash
fxtunnel udp 19132
```

UDP-туннели доступны с тарифа Base. Там же пять туннелей одновременно: пригодится игре с двумя портами или если хочется держать два сервера сразу. Как узнать порт и протокол своей игры и что делать с двумя портами, разобрано в статье [«Как играть с другом по сети в любую игру»](/blog/play-with-friends-over-internet/).
