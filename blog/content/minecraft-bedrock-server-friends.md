Свой сервер Minecraft Bedrock для друзей делается из двух программ. Первая — официальный Bedrock Dedicated Server от Mojang, он бесплатный и скачивается с minecraft.net. Вторая — туннель: команда `fxtunnel udp 19132` выдаёт адрес вида `fxtun.ru:20132`, и друзья с телефона или Windows добавляют его в список серверов. Белый IP и доступ к роутеру не нужны. Два ограничения стоит знать сразу. Bedrock работает по UDP, а UDP-туннели доступны с тарифа Base. На консолях игра штатно не умеет добавить внешний сервер, подробности ниже.

## Bedrock или Java: какой сервер нужен

Minecraft существует в двух изданиях, и серверы у них разные.

- **Java Edition** — версия для ПК с лаунчером. Сервер работает по TCP на порту 25565. Про неё отдельная статья: [«Майнкрафт по сети с другом без Хамачи»](/blog/minecraft-multiplayer-without-hamachi/).
- **Bedrock Edition** — версия для телефонов, Windows из Microsoft Store, Xbox, PlayStation и Switch. Сервер работает по **UDP** на порту 19132 ([minecraft.wiki](https://minecraft.wiki/w/Bedrock_Dedicated_Server)).

Если друзья играют на телефонах, вам нужен именно Bedrock. Игрок с Java на такой сервер не зайдёт, и наоборот.

## Шаг 1. Скачайте и запустите сервер

Bedrock Dedicated Server раздаётся бесплатно на [официальной странице загрузки](https://www.minecraft.net/en-us/download/server/bedrock) в виде ZIP-архива. Есть версии для Windows и Linux. По [minecraft.wiki](https://minecraft.wiki/w/Bedrock_Dedicated_Server), для Windows нужна Windows 10 версии 1703 и новее или Windows Server 2016, а из Linux официально поддерживается Ubuntu 22.04 и новее. На других 64-битных дистрибутивах сервер обычно тоже запускается, если есть нужные библиотеки.

Распакуйте архив в отдельную папку и запустите сервер.

Windows — двойной щелчок по `bedrock_server.exe` или из PowerShell в этой папке:

```powershell
.\bedrock_server.exe
```

Linux:

```bash
LD_LIBRARY_PATH=. ./bedrock_server
```

Переменная `LD_LIBRARY_PATH=.` нужна, чтобы сервер нашёл библиотеки из своей папки ([minecraft.wiki](https://minecraft.wiki/w/Bedrock_Dedicated_Server)). Когда в консоли появится сообщение о запуске сервера, он готов принимать игроков. Консоль не закрывайте: в ней же вводятся команды сервера, а остановить его можно командой `stop`.

### Что поправить в server.properties

Настройки лежат в файле `server.properties` в папке сервера. Для игры с друзьями важны несколько строк ([minecraft.wiki](https://minecraft.wiki/w/Server.properties)):

| Параметр | По умолчанию | Зачем трогать |
|---|---|---|
| `server-port` | `19132` | UDP-порт для IPv4. Оставьте как есть |
| `server-portv6` | `19133` | Порт для IPv6, для туннеля не нужен |
| `max-players` | `10` | Сколько игроков пустить одновременно |
| `gamemode` | `survival` | Режим игры |
| `difficulty` | `easy` | Сложность |
| `allow-list` | см. в файле | `true` — пускать только тех, кто в списке. Значение по умолчанию в шаблоне сервера и на вики расходится, проверьте своё |
| `online-mode` | `true` | Проверка аккаунтов Xbox Live |

После правки перезапустите сервер: `stop` в консоли и запуск заново.

Про `online-mode` полезно знать одну вещь. Даже если его выключить, игроки, которые подключаются не из локальной сети, всё равно должны войти в аккаунт Xbox Live, так написано в [описании параметра](https://minecraft.wiki/w/Server.properties). Каждому другу нужна учётная запись Microsoft, вошедшая в игру.

## Шаг 2. Откройте сервер через туннель

Установите клиент fxTunnel на тот же компьютер, где запущен сервер. Windows, PowerShell:

```powershell
irm https://fxtun.ru/install.ps1 | iex
```

Linux:

```bash
curl -fsSL https://fxtun.ru/install.sh | sh
```

Откройте новое окно терминала и войдите в аккаунт (его заводят на [fxtun.ru](https://fxtun.ru/register)):

```bash
fxtunnel login
```

Запустите UDP-туннель на порт сервера:

```bash
fxtunnel udp 19132
```

```console
Connecting to fxtunnel server...
Tunnel established!
UDP: fxtun.ru:20132
Forwarding to localhost:19132
Inspector: http://127.0.0.1:4040
Ready to receive connections
```

Строка `UDP: fxtun.ru:20132` — адрес для друзей. Порт у вас будет свой, из диапазона 20001–30000. Окно с туннелем не закрывайте: туннель работает, пока запущен клиент.

Если вместо адреса клиент пишет `Failed to connect: server rejected tunnel: UDP tunnels are not available on your plan`, значит, аккаунт на бесплатном тарифе. Там работают только HTTP- и TCP-туннели, а UDP открывается с тарифа Base.

## Шаг 3. Друзья добавляют сервер

На телефоне (Android, iOS) и в Windows-версии игры:

1. Открыть «Играть» и перейти на вкладку серверов.
2. Нажать кнопку добавления сервера.
3. В поле адреса ввести `fxtun.ru`, в поле порта — число из строки `UDP:`, в нашем примере `20132`. Название любое.
4. Сохранить и подключиться.

Адрес и порт в Bedrock вводятся в **разные поля**. Если вписать `fxtun.ru:20132` в поле адреса, а порт оставить стандартным 19132, игра постучится не туда.

Друг подключается к серверу fxTunnel, а не к вашему домашнему адресу. Ваш IP он не видит.

## А если друг на консоли

Здесь честный ответ: консольная версия не умеет штатно добавить внешний сервер, и туннель этого не меняет.

В статье о [серверах](https://minecraft.wiki/w/Server) на minecraft.wiki сказано, что к таким серверам заходят по адресу и порту из списка серверов, «кроме консолей». Статья о [Bedrock Dedicated Server](https://minecraft.wiki/w/Bedrock_Dedicated_Server) уточняет: игроки на Xbox, PlayStation и Nintendo Switch подключаются только через нестандартную настройку DNS или по локальной сети. Такие настройки DNS мы не проверяли и не описываем. Ограничение сидит в самой игре на консолях, а не в сети, поэтому ни проброс порта, ни туннель его не снимают.

Сервер с туннелем — для тех, кто играет на телефоне и Windows. Если в компании есть консольщики, обещать им подключение к такому серверу не стоит.

## Только свои: белый список

Адрес туннеля может утечь: скриншот в чате, пересланное сообщение. Чтобы на сервер зашли только ваши друзья, включите белый список.

В `server.properties`:

```properties
allow-list=true
```

Перезапустите сервер и добавьте друзей по нику Xbox (gamertag) командой в консоли сервера:

```text
allowlist add НикДруга
```

Список хранится в файле `allowlist.json` в папке сервера, его можно править и вручную ([minecraft.wiki](https://minecraft.wiki/w/Commands/allowlist)). Тот, кого нет в списке, получит отказ.

## Постоянный адрес и перезапуск

Пока клиент `fxtunnel` работает, порт за вами держится. Если пропадёт интернет, клиент переподключится и получит тот же номер. После перезапуска `fxtunnel` сервер выдаст первый свободный порт, и он может оказаться другим. Тогда друзьям придётся поправить порт в сохранённом сервере.

Чтобы этого избежать, попросите конкретный номер из диапазона 20001–30000:

```bash
fxtunnel udp 19132 --remote-port 20132
```

Если порт свободен, адрес будет одним и тем же при каждом запуске. Если его занял кто-то другой, клиент ответит `Failed to connect: server rejected tunnel: port 20132 is already in use`, выберите другой номер. Закрепить порт за аккаунтом навсегда нельзя: кто первым занял номер, того он и есть. Держите пару запасных вариантов.

`--remote-port 19132` запросить не получится: номер вне диапазона, сервер ответит `outside allowed range`. Поэтому друзьям всегда нужен и адрес, и порт.

## Если друг не может подключиться

**Порт в поле адреса.** Самая частая ошибка: `fxtun.ru:20132` вписали целиком в поле адреса. Адрес отдельно, порт отдельно.

**Туннель смотрит не на тот порт.** Если вы поменяли `server-port` в `server.properties`, команда туннеля должна указывать тот же номер: `fxtunnel udp <server-port>`.

**Сервер или туннель закрыт.** Закрыли окно консоли сервера или терминала с `fxtunnel`, компьютер ушёл в сон — сервер пропадает из сети. Для долгих сессий отключите спящий режим.

**Разные версии.** Сервер и игра должны быть одной версии. Игра обычно обновляется из магазина приложений, а сервер сам не обновляется: после обновления игры скачайте свежую версию со страницы загрузки. Перед заменой файлов сохраните копию папки сервера с миром и настройками.

**Нет в белом списке или не вошёл в Xbox Live.** Проверьте gamertag в `allowlist.json` и то, что друг вошёл в учётную запись Microsoft.

**Лаги у всех сразу.** Между сервером fxTunnel и вашим компьютером UDP-пакеты идут внутри одного TCP-соединения. Если на вашей домашней линии теряются пакеты, притормаживает весь туннель, а не один игрок. Помогает кабель вместо Wi-Fi на компьютере с сервером.

## Какой тариф нужен

Для Bedrock нужен один UDP-туннель на порт 19132, но UDP работает начиная с тарифа Base. Там же пять туннелей одновременно: можно рядом держать сервер Java Edition по TCP для друзей с ПК или карту мира в браузере по HTTP.
