У fxTunnel есть десктопное приложение для Windows, macOS и Linux. Оно делает то же, что клиент `fxtunnel` в терминале, но кнопками: выбрали тип туннеля, вписали локальный порт, нажали «Создать туннель» и скопировали адрес. Приложение работает с тем же аккаунтом и API-токеном, что и командная строка, а туннели из него подчиняются тем же тарифам. Скачать его можно в личном кабинете на fxtun.ru, в разделе «Скачать».

Ниже по порядку: установка, вход, первый туннель, наборы для повторного запуска, история и что в приложении пока есть только у командной строки.

## Где скачать

Файлы приложения лежат в личном кабинете. Войдите на [fxtun.ru](https://fxtun.ru), откройте раздел **Скачать** (адрес `fxtun.ru/downloads/files`, без входа он не откроется) и перейдите на вкладку **GUI клиент**. Публичная страница [fxtun.ru/downloads](https://fxtun.ru/downloads) рассказывает о клиентах, но файлов приложения на ней нет.

На вкладке — карточки сборок, которые сейчас лежат на сервере. Страница ждёт четыре: Windows (amd64), Linux (amd64), macOS Intel (amd64) и macOS Apple Silicon (arm64). Если какой-то из них на сервере нет, вместо кнопки «Скачать» будет серая карточка с пометкой «В разработке» и советом пока пользоваться CLI-версией.

Приложение — один исполняемый файл, установщика нет:

- **Windows:** скачайте `.exe` и запустите.
- **Linux:** сделайте файл исполняемым (`chmod +x` и имя файла) и запустите. Сборка для Linux использует системную библиотеку WebKitGTK 4.1. Если приложение не стартует и пишет про `libwebkit2gtk-4.1`, поставьте её из репозитория дистрибутива, в Ubuntu и Debian это пакет `libwebkit2gtk-4.1-0`.
- **macOS:** скачайте сборку под свой процессор. Это тоже голый исполняемый файл, а не приложение `.app` и не образ `.dmg`: при сборке релиза из пакета вынимается только сам бинарник. Скорее всего, понадобится `chmod +x` и подтверждение запуска в системе защиты macOS (Gatekeeper). Запуск на macOS мы не проверяли.

Приложение построено на Wails: это Go и веб-интерфейс внутри одного окна. Внутри тот же код туннелей, что у клиента командной строки.

## Вход

На экране входа сверху поле **Адрес сервера**. Для fxTunnel по умолчанию там уже стоит `tunnel.fxtun.ru:443`, менять не нужно. Поле пригодится, если вы развернули свой сервер fxTunnel.

Способов войти три:

- **Войти по почте.** Введите адрес почты, придёт код. Впишите его в поле «Код из письма» и нажмите **Подтвердить**. Если в аккаунте включена двухфакторная проверка, приложение попросит ещё код из приложения-аутентификатора.
- **Войти с Яндекс ID.** Приложение откроет браузер и будет ждать, пока вы подтвердите вход там.
- **По токену** (под разделителем «или подключиться по токену»). Вставьте API-токен в поле **Токен** и нажмите **Подключиться**. Токен создаётся в личном кабинете на сайте, в разделе «Токены», и начинается с `sk_fxtunnel_`.

Галочка **Запомнить учётные данные** включена по умолчанию. С ней приложение сохраняет вход в системном хранилище паролей и при следующем запуске входит само.

## Первый туннель

На **Главной** вверху блок **Быстрое подключение**:

1. **Тип** — HTTP, TCP или UDP.
2. **Локальный порт** — порт вашего приложения или сервера, например `3000`.
3. Для HTTP — **Поддомен** (необязательно). Без него сервер выдаст случайный.
4. Для TCP и UDP — **Удалённый порт** (необязательно). Без него сервер выдаст первый свободный: для TCP из диапазона 10000–20000, для UDP — из 20001–30000.
5. Нажмите **Создать туннель**.

Туннель появится в списке **Активные туннели** с адресом: `https://<поддомен>.fxtun.ru` у HTTP или `fxtun.ru:<порт>` у TCP и UDP. Рядом кнопки: **Копировать URL**, **Открыть в браузере** и закрыть туннель.

Пока активных туннелей нет, под формой видны шаблоны **Начните с шаблона**. Они заполняют форму готовыми значениями:

| Шаблон | Что подставит |
|---|---|
| Веб-разработка | HTTP, порт 3000 |
| API-сервер | HTTP, порт 8080, поддомен `api` |
| SSH-доступ | TCP, порт 22 |
| База данных | TCP, порт 5432 |
| Игровой сервер | TCP, порт 25565 |
| Свой вариант | пустая форма |

Шаблон только заполняет поля, туннель создаётся кнопкой. Поддомен `api` из шаблона может оказаться занят, тогда впишите своё имя.

## Что зависит от тарифа

Приложение ничего не меняет в тарифах: сервер проверяет туннель так же, как из командной строки.

- **Бесплатный тариф:** один туннель одновременно, HTTP или TCP. UDP-туннель сервер отклонит. Инспектор запросов недоступен.
- **Base:** пять туннелей одновременно, UDP, инспектор, резерв поддоменов и свой домен. Pro — пятнадцать туннелей, Business — пятьдесят.

В боковой панели приложение показывает ваш тариф и сколько туннелей, доменов и токенов уже занято.

## Инспектор запросов

У HTTP-туннеля в списке есть значок с подсказкой **Inspect traffic**. Он открывает инспектор: список запросов, которые пришли через туннель, с заголовками и телом запроса и ответа. Запрос можно повторить кнопкой **Replay** или изменить и отправить снова. Это удобно для вебхуков: событие пришло один раз, а обработчик можно гонять сколько нужно. Инспектор работает с тарифа Base. Как им пользоваться, подробно рассказано в статье [«Traffic Inspector: отладка HTTP-запросов»](/blog/traffic-inspector-debug-requests/).

## Наборы: туннели, которые нужны каждый день

Если вы открываете одни и те же туннели изо дня в день, сохраните их в **Наборы**. Раздел в боковом меню, кнопка **Новый набор**. Поля:

- **Название**, например «Фронтенд» или «Сервер Terraria»;
- **Тип**, **Локальный порт**;
- **Поддомен** для HTTP или **Удалённый порт** для TCP и UDP, оба необязательны;
- **Автоподключение при запуске**.

Сохранённый набор запускается кнопкой **Подключить** в разделе «Наборы» или в блоке **Сохранённые наборы** на главной. Наборы с автоподключением приложение поднимает само сразу после входа, в том числе при автоматическом входе после запуска.

Для постоянного адреса в наборе задайте поддомен или удалённый порт. Помните, что без них каждый запуск даёт новый адрес, а удалённый порт может оказаться занят кем-то другим. Закрепить поддомен за собой можно в разделе **Домены** кнопкой **Зарезервировать** — с тарифа Base. Подробнее — в статье [«Постоянный адрес туннеля»](/blog/permanent-tunnel-address/).

Наборы хранятся в локальной базе приложения и синхронизируются с аккаунтом: войдёте на другом компьютере — они подтянутся. Кнопки **Экспорт** и **Импорт** сохраняют наборы в файл `fxtunnel-bundles.json` и загружают их обратно.

## История подключений

Раздел **История** показывает все туннели, которые открывались из приложения: набор, тип, локальный порт, удалённый адрес, когда подключился, сколько длился и сколько данных прошло. Сверху фильтр по типу: все, HTTP, TCP, UDP. Очистить историю можно в разделе **Настройки**, пункт «Очистить историю подключений».

История пригодится, когда нужно вспомнить, на каком порту вчера работал игровой сервер, или проверить, сколько трафика прошло через туннель к демо.

Локальная база лежит в папке данных приложения:

- Windows: `%APPDATA%\fxTunnel\data.db`;
- macOS: `~/Library/Application Support/fxTunnel/data.db`;
- Linux: `~/.local/share/fxtunnel/data.db`.

## Настройки и работа в фоне

В **Настройках** есть тема оформления, язык (русский или английский) и сервер по умолчанию. Пункт **Сворачивать в системный трей** включён по умолчанию. На Linux и macOS с ним закрытое окно не останавливает туннели: приложение продолжает работать, а меню значка в трее открывает окно снова или завершает работу. На Windows значка в трее в текущей версии нет, и закрытие окна завершает приложение вместе с туннелями. Сверните окно, а не закрывайте его, пока туннели нужны.

Раздел **Логи** показывает журнал клиента с поиском и фильтром по уровню. Если туннель не поднялся, загляните туда в первую очередь.

## Чего в приложении нет

В форме туннеля нет полей для пароля (`--auth`), списка IP (`--allow-ip`) и таймеров `--auto-close` и `--max-lifetime`. Если туннель нужно закрыть паролем или пустить к нему только свои адреса, например для удалённого рабочего стола, пользуйтесь командной строкой: `fxtunnel http 3000 --auth team:Long-Pass-2026x` или `fxtunnel tcp 3389 --allow-ip 203.0.113.10`. Подробно — в статье [«Пароль и список IP для туннеля»](/blog/tunnel-password-and-ip-allowlist/).

Командная строка ставится одной строкой, `curl -fsSL https://fxtun.ru/install.sh | sh` или `irm https://fxtun.ru/install.ps1 | iex` на Windows, и работает с тем же аккаунтом: вход — `fxtunnel login`.
